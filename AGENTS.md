# Rotorheads

Operational rules for this server live in `.cursor/rules/dcs-host.mdc`. Read that before changing saves, hooks, or the mission workflow.

The owner hosts a LAN server from the DCS client on one PC. Scripts are in `Saved Games\DCS\Missions\Rotorheads`. The campaign save is the separate folder `Saved Games\DCS\rotorheads`. Host `RH Manual.miz` unless a newer mission is named. Do not respawn units from `persistence/Rotorheads.json` inside a mission file.
